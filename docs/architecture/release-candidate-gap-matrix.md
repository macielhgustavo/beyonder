## GAP MATRIX (baseline behavior)

Path shorthand: `models/`, `tasks/`, `intelligence/` and `agent/` are under `packages/runtime/src/`; `compute/src/` is under `packages/`; `apps/` paths are repository-relative. Each recommendation is scoped; absence of a reference feature alone is not a defect.

Additional original sources: the upstream [provider registry](https://github.com/tashfeenahmed/freellmapi/blob/4602fe2912337bb8b3c608572035d613ccdb0324/server/src/providers/index.ts) and [provider overview](https://github.com/tashfeenahmed/freellmapi/blob/4602fe2912337bb8b3c608572035d613ccdb0324/docs/en/providers/OVERVIEW.md) reinforce separating registered adapters from catalog eligibility and quotas. No upstream provider expansion or financial-credit integration was adopted. AgentKit and x402 references in the original research concern wallet/payment execution and remain outside this stabilization scope. The original freellmpool note has no precise source URL/version, so it is not treated as verified implementation evidence.

## Implementation gate

Implement only confirmed P1 groups **H1** (persistent classified operational exclusion and bounded cascade), **L1** (legacy inference/agent truth), **Q1** (quota/provider truth), **V1** (single authoritative validation and empty-catalog semantics). P2 items remain explicit backlog, not silently presented as implemented. No new provider, scheduler, alias product, executor, wallet, treasury, trading, x402, self-modification or multi-agent system.

Do not adopt reference hardcoded model demotions, unlimited fallback, broad shell tools, financial actions, or DB-stored encryption master keys. The existing zero-money, single-use approval and external-read policies take precedence over reference convenience.

Safety decisions: auth exclusion is provider-wide because Beyonder currently resolves one active credential set per provider; a 403 is model-scoped because permission denial need not revoke the entire account. Daily/account exhaustion defaults conservatively to 24 hours unless explicit Retry-After supplies a future reset. This intentionally does not copy a midnight reset assumption. Ordinary 400/invalid output can cascade but does not globally quarantine a healthy provider. Remote survival inference is still at most one attempt per inference sequence, plus an eligible zero-money/no-external-quota local fallback.

Evidence and limitations:

- The recent health window is the last 100 terminal inference samples, not a seven-day time window. Metrics describe transport availability separately from output quality.
- No automatic background probes or model downloads were added. A daily probe script exists in E; its deployment scheduler was not independently verified. Live-provider billing/free-tier availability was not revalidated by paid or remote generation.
- Exact live quota counters, provider-specific reset semantics, half-open concurrency leases, user-configurable aliases, automatic vault unlock, cross-process JSON onboarding locks and automatic task recovery remain P2 work. A cooldown check is not a distributed quota reservation.
- Model-specific cooldown is visible in task/routing audit; the Resources list summarizes provider-level health. It does not claim all models of a provider are available.
- Credential validation clears authentication exclusion only via validated operator setup. Stored encrypted keys are never returned to the frontend, and no master key is stored beside ciphertext.
- No P0 was confirmed. All four confirmed P1 groups above are addressed; remaining P2 gaps are not disguised as parity or release features.

Validation: 326 backend tests and 20 Control Center tests pass (346 total, 37 new regressions). Full backend and Control Center build/typecheck suites, browser, web-evals, autonomy, hardening, opportunities, approvals, work-loop, Control Center fixture/security/production-supervisor smokes, and read-only marketplace smoke pass. Monetary cost remains $0. AgentWork still returns HTTP 500; that external-source failure is reported, not interpreted as absence of opportunities. The work-loop's $5 settlement is fixture-only, not real revenue. See PR #18 for the final commit and CI checks.
