# v0.5.2 — Real Work Loop

`WorkRunManager` persists the opportunity lifecycle in the existing state store. A run keeps application, execution, deliverable, settlement, task, cost, and revenue data together and survives process restart. Application and submission approvals remain separate, opportunity-bound, action-bound, auditable, and single-use.

## Lifecycle and evidence

The deterministic loop is:

`SELECTED → AWAITING_APPLICATION_APPROVAL → APPLICATION_SENT → WORK_AVAILABLE → EXECUTING → WORK_READY → AWAITING_SUBMISSION_APPROVAL → AWAITING_SETTLEMENT → COMPLETED`.

`TaskExecutor` completion only produces execution evidence. A deliverable must verify `PASS` before submission approval. Submission only produces `AWAITING_SETTLEMENT`; `realizedRewardUsd` changes only after validated `SettlementEvidence` with positive USD/USDC amount, timestamp, and source or external reference. Completion and submission never imply payment.

`beyonder work start|list|inspect|status|send-application|settlement|record-settlement` and `beyonder economy revenue` expose the loop without a “mark paid” shortcut. Manual external actions can be recorded with actor and provenance, so human work is not represented as Beyonder execution.

## Sources and reliability

AgentWork remains read-only and is tracked as `UNAVAILABLE` when its catalog returns HTTP 500. Open Bounty is an additional read-only public source using `GET /api/v1/bounties`; its current smoke exposed one $2 USDC survey candidate with wallet/on-chain requirements, so it is not automatically applied. The current Open Bounty API documentation describes the public list endpoint and separately authenticated/payment-bearing operations: https://www.openbounty.app/api/docs.

`SourceReliabilityStore` records health, latency, availability, error types, malformed responses, successful discoveries, and last success/failure. Source health is operational metadata and is intentionally separate from economic opportunity quality.

No wallet, trading, payment, account creation, external proposal, or real submission is performed by this release. The deterministic fixture demonstrates settlement evidence of $5 at zero monetary cost and updates economic memory only after evidence.
